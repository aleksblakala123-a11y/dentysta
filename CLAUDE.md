# Wytyczne Projektu: Stomatologia Web

- **Język:** Polski
- **Styl:** Modern HTML5 / CSS3 / Tailwind (czysty, czytelny kod)
- **Cel:** Strona wizytówkowa dla gabinetu stomatologicznego w Świdniku
- **Zasady UX:** 
  - Wszystkie numery telefonów muszą być klikalne (`href="tel:..."`)
  - Wyraźne przyciski Call to Action ("Umów wizytę", "Zadzwoń")
  - Pełna responsywność (RWD) dla smartfonów
